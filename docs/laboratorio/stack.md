# Stack

| Camada | Tecnologia | Quando usar |
|---|---|---|
| Dados / ETL | Python, Pandas, NumPy | Coleta, limpeza e transformação de dados |
| Dashboards rápidos | Streamlit | Protótipos, pesquisas e projetos do nivelamento |
| APIs | Spring Boot (Java) | APIs de produção, seguras e documentadas |
| Serviços de ML | FastAPI (Python) | Modelos e serviços de dados expostos via API |
| Front-end | Next.js | Sites e plataformas web |
| Banco de dados | PostgreSQL | Padrão para todos os projetos |
| Infraestrutura | Docker, Coolify, VPS Hostinger | Deploy de tudo que vai para produção |
| Versionamento | Git + GitHub | Código, issues e roadmap |
